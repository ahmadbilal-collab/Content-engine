# Bharte Chalo - Show Planning Guide

## Show Identity

**Name:** Bharte Chalo (بڑھتے چلو) - Keep Moving Forward

**Tagline:** "Sochein Behtar, Faisla Karein Smarter, Aagey Barhein"
*(Think Better, Decide Smarter, Move Forward)*

**Mission:** Educate everyone in Pakistan on AI, IT, leadership, and innovation - helping them think better, decide smarter, and move forward.

**Schedule:** 2 Episodes Per Week | 90 Minutes Each


### Release Schedule
- **Episode 1:** Tuesday 6 PM PKT (Start of work week momentum)
- **Episode 2:** Friday 6 PM PKT (Weekend learning time)

### Why This Schedule?
- Tuesday: People are settled into work week, ready to learn
- Friday: Weekend ahead for applying what they learned
- 3 days gap: Time to collect questions, prepare quality content

## Using the Script Generator

### Generate Full Episode
```bash
python main.py radio "Your Topic Here" "Theme Name"

# Examples:
python main.py radio "What is ChatGPT" "AI Fundamentals"
python main.py radio "Starting Freelance Career" "Freelancing Success"
python main.py radio "Leading Remote Teams" "Leadership in Digital Age"
```

### Generate Episode Series
```bash
python main.py radio-series "Main Topic" 4

# Examples:
python main.py radio-series "Understanding AI" 6
python main.py radio-series "Freelancing Masterclass" 4
python main.py radio-series "Pakistan Startup Ecosystem" 5
```

### Output Location
Scripts are saved to: `output/radio/YYYY-MM-DD/`
- JSON format for data processing
- Markdown format for reading/editing

## Quick Start: Your First Episode

### Step 1: Choose Your Topic
Pick something you're passionate about that helps Pakistani listeners.

### Step 2: Generate Script
```bash
python main.py radio "Your Topic" "AI Fundamentals"
```

### Step 3: Review & Personalize
- Read through the generated script
- Add your personal stories and examples
- Adjust language balance if needed
- Practice the Urdu phrases

### Step 4: Record
- Find a quiet space
- Speak naturally, like talking to a friend
- Don't worry about perfection - energy matters more

### Step 5: Release & Engage
- Share on your platform
- Create social clips
- Respond to listener feedback
- Plan next episode based on response

## Show Philosophy Reminders

1. **Accessibility First** - If a 10th grader can't understand it, simplify it
2. **Pakistan Always** - Every topic must connect to Pakistani reality
3. **Action Required** - No episode without practical takeaways
4. **Bilingual Natural** - Mix languages like we actually speak
5. **Hope & Progress** - Always end with motivation and possibility
