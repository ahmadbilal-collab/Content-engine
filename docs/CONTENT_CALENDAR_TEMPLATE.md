## Promotion Checklist (Per Episode)

### Before Release
- [ ] Episode thumbnail/artwork created
- [ ] Show notes written (bilingual)
- [ ] 3 quote graphics prepared
- [ ] Audio clips for social (30-60 sec) cut
- [ ] Email/message to community drafted

### Release Day
- [ ] Upload to hosting platform
- [ ] Share on WhatsApp groups
- [ ] Post on LinkedIn
- [ ] Post on Twitter/X
- [ ] Post on Facebook
- [ ] Share in relevant communities

### Post-Release (48 hours)
- [ ] Respond to all comments
- [ ] Share listener feedback
- [ ] Note improvements for next time
- [ ] Update episode if needed
